# BitLinks 🔗

A modern full-stack URL shortening platform built with Next.js and MongoDB.

## Features

- Create custom short URLs
- Fast redirection system
- MongoDB database integration
- Responsive modern UI
- REST API support
- Postman collection included
- SEO-friendly architecture

## Tech Stack

- Next.js 15
- React 19
- MongoDB
- Tailwind CSS
- JavaScript
